# 仪表盘

在 `.dashboard` 文件中组合已保存的 Eidos 视图和普通文件，包括插件文件视图。配置文件保存 JSON 布局和相对引用，数据仍留在各自的源文件中。

需要 **Eidos Lite 0.29.0** 及以上版本和插件 API **3.7.0**。安装并在 Space 启用后，选择 **新建文件 → 仪表盘**，添加文件；对 `.eidos` 文件选择已保存的视图。名称、按钮和文档跟随应用语言，切换语言保留面板及未保存的文件选择。

面板平时只显示标题和内容，悬停或聚焦时显示操作菜单。选择 **编辑布局** 后可重命名、重排、调整大小。拖动手柄移动面板，或聚焦手柄后按空格，再用方向键选择位置，回车放置、Escape 取消。拖动右侧、底部或右下角改变大小；拖动提供实时预览，松开后应用一条可撤销修改，Escape 取消。聚焦边缘后也可使用方向键调整。

保存按钮或 Command/Ctrl+S 写入布局，撤销和重做使用宿主文档历史。文件冲突保留工作副本；过期编辑会在恢复字段中保留提出的 JSON，供文本编辑器协调。

最多支持 12 个只读面板。引用必须位于当前 Space，路径相对于配置文件目录。不支持嵌套仪表盘、跨 Space 引用、全局筛选联动和整页图片导出。Eidos 面板响应 Space 更新，普通文件可通过面板菜单刷新。不可用的文件或插件显示面板错误。CLI Serve、Android 和 iOS 不支持此版本。

## 开发

使用 Node.js 22.12 及以上版本和 SDK/tools 0.9.0，运行 `npm ci`、`npm test`、`npm run check -- --target lite` 和 `npm run pack:plugin`。插件只通过版本化文档 API 修改自己的配置；资源渲染、权限和路径检查由宿主负责。
